# Notion Like

仿 Notion 页面的 Obsidian 主题，亮色和暗色两套，跟随系统自动切换。

## 排版规格

数值按 Notion 页面实测还原。

| 项目 | 规格 |
|---|---|
| 正文 | 16px，行高 1.5，宽度 708px |
| 块与块之间 | 8px |
| 页面标题 | 40px，粗细 700，行高 1.2 |
| H1 / H2 / H3 / H4 | 30 / 24 / 20 / 18px，粗细 600，行高 1.3 |
| 标题上方间距 | H1 38px · H2 28px · H3 22px · H4–H6 20px |
| 标题下方间距 | 11px |
| 加粗 | 600 |

## 样式

- 配色：Notion 的文字色、暖灰侧边栏，强调色 `#2383e2`；暗色背景 `#191919`
- 行内代码：灰底红字
- 有序列表：按嵌套层级显示 `1.` → `a.` → `i.`，每三层循环（支持九层），编号使用正文颜色
- 引用：左侧 3px 竖线，无背景
- 代码块、表格、分割线、勾选框、标签：按 Notion 的尺寸和颜色
- Callout：内置类型改为 Notion 风格的彩色底块，另外支持 9 种 Notion 颜色

```markdown
> [!yellow] 标题
> 内容
```

可选颜色：`gray` `brown` `orange` `yellow` `green` `blue` `purple` `pink` `red`

## 编辑模式

编辑模式（实时预览）下，段落之间的空行会压缩为 8px，让编辑时的间距和阅读模式一致。光标所在的空行保持正常高度，方便输入。

建议搭配 [Notion Enter](../../plugins/notion-enter) 插件使用：Enter 新起一个块，Shift+Enter 段内换行。

有序列表在阅读模式下只需主题；实时预览还需更新并启用 Notion Enter。编号按 Markdown 中的数字转换，例如二级的 `2.` 显示为 `b.`，三级的 `4.` 显示为 `iv.`；光标进入编号或选中编号时显示原始数字，方便编辑。源码模式保持原样。阅读模式沿用 Markdown 自带的顺序编号，因此原文若每项都写 `1.`，阅读模式会递增，实时预览仍按原文显示。

## 注意

如果开着其他 CSS 片段，它们可能覆盖主题的排版。效果不对时，先在「设置 → 外观 → CSS 代码片段」里关掉其他片段对比。
